# Global Fuel Insights

Create a professional 'Global Fuel Economics Dashboard (2020–2026)' covering 84 countries across 7 global regions. Generate realistic sample data representing 10 variables: Country, Region, Income Level, GDP per Capita, Fuel Type (Petrol, Diesel, LPG), Base Price, Tax Amount, Subsidy Amount, Net Retail Price, and Volatility Index. At the top of the page, add a persistent Global Filter Bar with dropdowns for Fuel Type, Global Region (7 options), Income Level, and Year (2020–2026), along with a 'Download CSV' button.
